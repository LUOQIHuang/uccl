## 轮间漂移限制了收益归因

实际时间顺序为 A1 9.058 → B1 8.817 → C1 7.828 → C2 7.813 → B2 7.825 → A2 8.234 ms。全开基线 A1 与 A2 相差约 **824 μs**，B1 与 B2 相差约 **992 μs**。各正式 BF16 配置的轮内 CV 最高只有 0.85%，说明这两组偏慢各自持续了整轮。模块与关键配置未见漂移，日志无法定位造成轮间状态变化的因素。

因此 13.58% 是相对较慢的 A1 的观测差值。第 2 轮 C 相对 A 缩短约 **421 μs（5.11%）**，同轮 C 与 B 仅相差 12.43 μs（0.16%）。预定的“两轮 C/B 的绝对差均低于 1%”门槛因第一轮的 11.22% 未通过，无法据此宣布等效或稳定的 5%–14% 收益。

FP8 上 C 相对 A 分别 +0.52% 和 −0.26%，Combine 两种配置的变动均在 0.14% 以内。B 的两种 Combine 配置在两轮中均变慢约 0.95%–1.92%。这些是各配置的观测值，进一步说明 C 值得作为较小范围的备选。正式正确性通过覆盖本轮固定配置，长期缓冲复用和其他负载仍待验证。[全部测点](urma_fence_scope_01_summary/rounds.csv)

## 与追平目标的距离

C 在当前两轮实测为 **7.813–7.828 ms**，与历史 verbs 的 **7.149–7.216 ms** 相比，仍有约 **0.60–0.68 ms** 的量级差距。这个对照跨实验，仅用于衡量目标差距。主线仍是定位 204 发送侧的完成交付和后续 WRITE，是否拖住 202 最后一批 token。当前数据没有采集那些阶段，无法指出 C 将哪一段缩短了 421 μs，也无需为放宽范围重复整套矩阵。[历史 verbs 对照一](BACKEND_MATCHED_ANALYSIS.zh-CN.md) · [历史 verbs 对照二](../../fadd_path/results/fadd_path_01/BACKEND_COMPARISON.zh-CN.md) · [204 密集完成采样](../../fadd_path/results/fadd_dense_01/ANALYSIS.zh-CN.md)
