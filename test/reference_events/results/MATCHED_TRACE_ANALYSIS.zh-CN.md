## GPU事件

已保留first token、first remote payload WRITE、last remote epoch visible三个点。按同一Sender CTA的事件0→1间隔取中位数，原始记录值为202 FP8/BF16约354.14/450.07μs、204约397.10/476.45μs；这是首批准备/协调跨度，不是纯token拷贝耗时。

本轮有效GPU记录没有早于CPU origin的时间值，旧轮204的首点滞后现象未按相同方式出现；但clock_stats最大间隔202约99.97μs、204约355.55μs，含启动/结束和尾间隔，不能据此保证事件微秒精度。旧轮约1ms与本轮约0.4ms的Sender跨度差异不能直接称作实现加速。

事件2没有最终Receiver结束点，也不能把本机发出的WRITE与本机收到的远端数据强行一一对应，因此没有完整网络/接收/输出的可相加分解。
