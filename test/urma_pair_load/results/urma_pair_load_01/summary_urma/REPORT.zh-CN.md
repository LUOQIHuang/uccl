# URMA四对等量负载对照

每迭代固定4对WRITE/FADD、1837056B，单线程；serial4逐对等待，queue4单队列四对同时在途，lanes4四队列各一对。
先判断等量整批SDK跨度，再看对应请求W→A间隔。queue4按原实现先W0..W3后A0..A3，间隔增长本身不能判定退化。
时间来自本端SDK观测；同批返回可为0，负间隔保留。GPU校验与TCP同步不在计时内。

整批值为各轮迭代均值的中位数。contrasts.csv保留每轮成对差值；positions.csv按请求位置分别统计，避免混合掩盖排队。
稳定门槛：各轮整批CV≤5%，轮均值跨度/中位数≤5%。失败保留日志，不自动重跑。
SDK提交耗时可能属于同一次链式调用，不能相加。单对在途时延在并发情况下重叠，也不能相加当整批时延。
本实验不是完整Normal：没有原FIFO/Proxy循环、head反馈、双向同时发送或计时内GPU消费。四对未复现不能排除更大负载或多线程触发。
